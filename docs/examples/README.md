## Explore an example

1. Identify its inputs, reset, clock, and displays.
2. Inspect component Properties and module interfaces.
3. Add probes to the signals you want to follow.
4. Start simulation and release reset when the example instructions call for it.
5. Pause or step to study changes.
6. Open a live module instance to follow internal signals.
7. Stop, edit the circuit or Verilog source, and save your version.
